# Store material

- `listing.md`: names, subtitles, descriptions and keywords (Chinese and English)
  for App Store Connect and AppGallery Connect.
- `capture_screenshots.sh <iphone-udid> <ipad-udid> <raw-dir>`: captures the four
  scenes in both languages on booted simulators (iPhone 18 Pro Max, iPad Pro
  13-inch) with the simulator build installed.
- `compose_screenshots.py <raw-dir> <output-dir>`: adds the captions and writes
  the iPhone 6.9", iPhone 6.5" and iPad 13" sets.
